# MovieApp

Bu proje, bir film uygulamasıdır. **React** kullanarak frontend kısmını, backend
kısmını ise doğrudan **Node.js** ile geliştirdim. Uygulamada **GET**, **POST**
ve **DELETE** HTTP metodları kullanılarak film verisi üzerinde işlemler
yapılmaktadır. Veri alma ve gönderme işlemleri için **Axios**, durumsal yönetim
için ise **React Query** kütüphaneleri kullanılmaktadır.

## Özellikler

- Film listesi görüntüleme (GET)
- Yeni film ekleme (POST)
- Film silme (DELETE)

## Kullanılan Teknolojiler

- **Frontend**: React, React Router, React Query, Axios, React Icons
- **Backend**: Node.js, HTTP modülü
- **Diğer**: Nodemon (geliştirme ortamı için)
